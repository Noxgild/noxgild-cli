# Code of Conduct

Noxgild adopts the **Contributor Covenant, version 2.1** for participation in this public project.

The canonical text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

Project maintainers are expected to apply that standard consistently and in good faith.

For conduct concerns, use the support channel at https://noxgild.com/support. Do not use a public issue to disclose private or sensitive personal information.
