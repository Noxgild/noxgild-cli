# Changelog

## 1.0.2 - 2026-10-09

- Forward the approved account tenant to the Windows installer so an existing device is only reused for the correct account.
- Use the production API's recoverable runtime replacement and preserve the working device identity on pairing failures.
- Keep connection approval explicit and one-time, with no GitHub Actions required for publication.

## 1.0.1 - 2026-10-08

- Expanded npm metadata for discovery and trust.
- Reworked the README into a complete install-to-approval onboarding guide.
- Documented Windows, macOS, and Linux support.
- Clarified the difference between local Browser execution and hosted Cloud Browser.
- Added public security, privacy, support, and contribution guidance.
- Added cross-platform CI and package-content release gates.
- Prepared trusted npm publishing with provenance.
