# Support

## CLI bugs and documentation

Use GitHub Issues for reproducible bugs in the public bootstrap CLI and for documentation corrections.

Before filing an issue, please include the CLI version, operating system, architecture, the command you ran, and a minimal reproduction when possible.

## Account, billing, or customer-specific support

Use https://noxgild.com/support.

## Security

Do not report undisclosed vulnerabilities in a public issue. Use GitHub private vulnerability reporting or the security contact published at https://noxgild.com/.well-known/security.txt.

## Never post secrets

Do not post:

- passwords,
- access tokens,
- pairing secrets,
- private keys,
- screenshots containing sensitive account information,
- production command payloads containing credentials,
- or private customer files.
